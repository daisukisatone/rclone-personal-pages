Privacy Policy

Rclone Personal · Last updated: November 5, 2026

本应用仅用于所有者本人在设备与 Google Drive 之间同步文件。此说明网页不接收云盘文件、OAuth 令牌或客户端密钥，也不提供登录功能。授权可在 Google 账号设置中撤销。

1. Scope and operator

Rclone Personal is a personal-use OAuth configuration maintained by daisukisatone for locally installed rclone and RClone Manager. This policy describes that configuration and these informational webpages, not unrelated services or other users' installations.

2. Information accessed and why

With the account owner's consent, the installed tools access Google Drive file contents and metadata such as file names, identifiers, sizes, modification times and folder structure. These are used to list, compare and synchronize the configured locations.

Full Drive authorization can permit access to all files in the authorized account. Local synchronization paths and filters limit which files are actually processed. OAuth access and refresh tokens are used to authenticate requests; this website does not collect the owner's Google password.

3. Storage and retention

Files remain in the owner's Google Drive and in the local locations selected by the owner. OAuth credentials are stored in the local rclone configuration. The installed tools may retain synchronization state, file listings, metadata and diagnostic logs on the device.

Local files and configuration remain until the owner removes them. Google Drive files, deleted items and revisions follow the owner's Drive settings and Google's retention behavior. Uninstalling the application or revoking authorization does not by itself delete previously synchronized files.

4. Use and sharing

This personal configuration uses Google Drive data only to perform the synchronization and related file-management actions requested by the owner. It does not sell Drive data, use it for advertising, or train AI models. No separate Rclone Personal server is operated to collect Drive files or OAuth credentials.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

5. Control and revocation

The owner can stop synchronization, change its paths and filters, remove locally stored credentials, or revoke the application's access through Google Account third-party connections. Revoking access prevents future authorized requests once the credentials are invalid, but does not remove existing local or cloud copies.

6. This website and hosting

These pages contain no sign-in form, analytics scripts or advertising code. They are hosted using GitHub Pages. GitHub may record visitors' IP addresses for security purposes as described in the GitHub Privacy Statement. Visiting these pages does not grant access to a Google account.

7. Contact and changes

Questions or corrections can be raised through the website repository's issue tracker. Do not post tokens, passwords, private documents or other sensitive information. Material changes to this policy will be reflected on this page with an updated date.

Rclone Personal

Personal Google Drive file synchronization, operated by daisukisatone using locally installed rclone and RClone Manager.

这是个人自用的 Google Drive 同步配置说明页面，用于说明 OAuth 应用的用途和数据处理方式。此网站不提供网盘登录、文件上传或账号注册功能。

What this application does

The installed desktop tools synchronize files between the owner's Google Drive and a locally configured folder. Depending on the owner's settings, synchronization may download, upload, update, rename or delete files to keep the selected locations in agreement.

This is an independent personal configuration, not a public file-storage service and not an official Google service. This website contains information only; it does not run the synchronization engine.

Google account access

The desktop application uses Google OAuth to obtain the owner's consent. Full Drive access is requested so rclone can synchronize existing files and folders, including files not originally created by this application.

The OAuth grant can permit access to all files in the authorized Drive account. The paths and filters configured locally determine what is actually synchronized. No Google password is entered into this website.

Data handling

Drive files, metadata and authorization tokens are handled by Google and the owner's locally installed tools. This project does not operate a separate server that receives the owner's Drive contents. This website never asks for OAuth tokens or client secrets.

Read the privacy policy for details about access, storage, retention and revoking authorization.
